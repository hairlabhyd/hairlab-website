📍 STEP 1: Open Namecheap DNS Settings
  1. Open https://www.namecheap.com and login
  2. Hover over your username (top left) → click "Dashboard"
  3. Find hairlab.one in your domain list
  4. Click "Manage" next to hairlab.one
  5. Click the "Advanced DNS" tab (top of page)
📍 STEP 2: Add 2 DNS Records
In the "HOST RECORDS" section, add these 2 records

Record #1: A Record (for hairlab.one)

TypeHostValueTTL
A Record @ 76.76.21.21 Automatic
👆 Click "Add New Record" → Type = A Record → Host = @ → Value = 76.76.21.21 → TTL = Automatic

Record #2: CNAME Record (for www.hairlab.one)

TypeHostValueTTL
CNAME Record www cname.vercel-dns.com Automatic
👆 Click "Add New Record" → Type = CNAME Record → Host = www → Value = cname.vercel-dns.com → TTL = Automatic
⚠️ If you see any old records (like a default "Parking Page" or "URL Redirect"), click the trash icon 🗑 next to them and DELETE them. Keep only the 2 records above.
👆 Click the orange "Save All Changes" button at the bottom when done
📍 STEP 3: Wait & Refresh Vercel
  1. Wait 5-30 minutes for DNS to propagate
  2. Go back to Vercel → https://vercel.com/hair-lab/hairlab-website/settings/domains
  3. Click the "Refresh" button next to hairlab.one
  4. You should see a green checkmark ✅ "Valid Configuration"
🎉 When you see green checkmarks on both hairlab.one AND www.hairlab.one:

Your website is now LIVE at https://hairlab.one 🎉

Visit it on your phone, send it to friends, share on Instagram. You're live!
⏳ DNS can take 5-30 minutes to propagate. If it still says "Invalid Configuration" after 30 min, refresh the page. If still wrong after 1 hour, send me a screenshot.
