📍 STEP 1: Create a New Repository
Open this URL: https://github.com/new
🔒 github.com/new

Create a new repository

A repository contains all project files, including the revision history.

Great repository names are short and memorable.
Public — Anyone on the internet can see this repository. ← PICK THIS ONE
Private — You choose who can see and commit to this repository.
Add a README file
Add .gitignore
Choose a license

Open this URL: https://github.com/settings/tokens/new
🔒 github.com/settings/tokens/new

New personal access token (classic)

What's this token for? (just a label)
Pick "7 days" from the dropdown
